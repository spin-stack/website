## Three things it does

<Bento>
<BentoCard size="big" art="isolation" icon="machine" title="Isolate: a whole machine, not a container" feature="A machine per workspace: KVM, its own kernel, root, a persistent disk, SSH">
Every workspace is a KVM virtual machine with its own kernel, root and a persistent disk. A person or an agent can install anything and break anything: nothing reaches the workspace next door, or the host.
</BentoCard>
<BentoCard size="wide" icon="diff" title="Inspect: snapshot, diff, roll back" feature="A diff of the files that changed between two snapshots">
A snapshot before, with the memory of the running processes. Every file added, modified or removed between two snapshots, read by a separate machine. Restore, and the processes are running where they were.
</BentoCard>
<BentoCard size="wide" icon="shield" title="Control: closed until you open it" feature="Egress is closed by default; policies, by tag, name what a workspace may reach">
Egress is closed by default, and policies name what a workspace may reach. A team's secret stays on the host's proxy and never enters the workspace. All of it in your AWS account, where the logs stay too.
</BentoCard>
</Bento>

## And

- **Built for agents.** [Claude Code and Codex on every workspace's PATH](<feature:Claude Code and Codex on every workspace's PATH, at the versions the release pins, with their own defaults>), API keys with scopes, JSON output.
- **Secrets the workspace never holds.** [A brokered rule](<feature:A brokered rule names whose it is, the agent's or the person's: one policy says what each may reach and with what>) adds the team's secret on the way out, one for the person and one for the agent.
- **Moves while it runs.** [A running workspace goes to another host](<feature:Move a running workspace to another host, its processes as they are>) with its processes as they are.
- **Asleep when idle, awake as it was.** [A workspace nobody uses is suspended](<feature:Suspend with the processes where they are; a start resumes them>), after asking first, and a start resumes it.
- **Reset in one command.** [A disk goes back to what it was created from](<feature:Reset a disk to what it was created from>), its snapshots kept.
- **In your AWS account.** [One OpenTofu module installs it](/aws/overview/). There is no hosted version, so your code and your data stay in your account.

## Straight answers

<Answers icons={['cloud', 'chip', 'kernel', 'nogpu', 'region']}>

- **AWS only.** One OpenTofu module installs Spinbox in your account. There is no hosted version.
- **x86-64 only.** Runners are x86-64 machines with nested virtualization.
- **Linux guests only.** A workspace boots the kernel Spinbox provides.
- **No GPUs.** There is no way to ask for a runner of a particular kind.
- **One region, one control plane.** An installation lives in one AWS region.

</Answers>
