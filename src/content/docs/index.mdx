## What you get

<Bento>
<BentoCard size="big" art="isolation" icon="machine" title="A whole machine, not a container" feature="A machine per workspace: KVM, its own kernel, root, a persistent disk, SSH">
Every workspace is a KVM virtual machine with its own kernel, root and a persistent disk. Install anything, break anything: nothing reaches the workspace next door.
</BentoCard>
<BentoCard icon="memory" title="Snapshots with memory" feature="Snapshots with memory, resumed with their processes">
Restore and the processes are running where they were.
</BentoCard>
<BentoCard icon="diff" title="A diff of everything" feature="A diff of the files that changed between two snapshots">
Every file added, modified or removed between two snapshots.
</BentoCard>
<BentoCard size="wide" icon="shield" title="Closed until you open it" feature="Egress is closed by default; policies, by tag, name what a workspace may reach">
Egress is closed by default. Policies name what a workspace may reach, and you can watch what it reached, looked up and was refused.
</BentoCard>
<BentoCard size="wide" icon="key" title="Secrets the workspace never holds" feature="A brokered rule names whose it is, the agent's or the person's: one policy says what each may reach and with what">
The host's proxy stands in for a brokered name and adds the team's secret on the way out. The person and the agent in one workspace each get their own.
</BentoCard>
<BentoCard icon="agent" title="Built for agents" feature="Claude Code and Codex on every workspace's PATH, at the versions the release pins, with their own defaults">
Claude Code and Codex on the PATH, API keys, JSON output, and a machine an agent can break and you can undo.
</BentoCard>
<BentoCard icon="move" title="Moves while it runs" feature="Move a running workspace to another host, its processes as they are">
A running workspace goes to another host with its processes as they are.
</BentoCard>
<BentoCard size="wide" icon="cloud" title="In your AWS account" href="/aws/overview/">
One OpenTofu module installs it in your account. There is no hosted version, so your code and your data stay in your account.
</BentoCard>
<BentoCard size="wide" icon="moon" title="Asleep when idle, awake as it was" feature="Suspend with the processes where they are; a start resumes them">
A workspace nobody uses is suspended with its processes where they are, after asking first, and a start resumes them.
</BentoCard>
</Bento>

## Straight answers

<Answers icons={['cloud', 'chip', 'kernel', 'nogpu', 'region']}>

- **AWS only.** One OpenTofu module installs Spinbox in your account. There is no hosted version.
- **x86-64 only.** Runners are x86-64 machines with nested virtualization.
- **Linux guests only.** A workspace boots the kernel Spinbox provides.
- **No GPUs.** There is no way to ask for a runner of a particular kind.
- **One region, one control plane.** An installation lives in one AWS region.

</Answers>

Each answer is a limit row of the [status page](/reference/status/), held to the code by a test.
The rest are on [Limitations](/overview/limitations/).
