## What you get

<CardGrid>
	<Card title="A machine per workspace" icon="laptop">
		Each workspace is a KVM virtual machine with its own kernel, root access, a persistent disk and SSH. Workspaces share no kernel with each other or with the host.
	</Card>
	<Card title="Snapshots, with memory" icon="document">
		Take a snapshot of a running workspace's disk, or of its disk and memory. From a memory snapshot, processes continue from the instant it was taken.
	</Card>
	<Card title="Rollback and diff" icon="random">
		Put a workspace back to any snapshot. List every file that was added, removed or modified between two snapshots.
	</Card>
	<Card title="Egress you decide" icon="approve-check">
		By default a workspace's network is closed. Network policies name what it may reach, and you can see what it did reach.
	</Card>
	<Card title="In your account" icon="seti:terraform">
		One OpenTofu module installs the whole thing in your AWS account. Runners start when a workspace needs one and scale back to none when nothing is running.
	</Card>
	<Card title="For people and agents" icon="rocket">
		Use it from the dashboard, from the CLI, from VS Code over SSH, or from an agent with an API key.
	</Card>
</CardGrid>
